# Кадровые документы

## Что здесь лежит

Кадровая документация ТОО «КМГ-Сервис»: положения об оплате труда, отпусках и соцпакете,
регламент командировок и вахты, правила внутреннего трудового распорядка, приказ о графике
отпусков, материалы по адаптации и оценке персонала, расчётные модели в Excel и бренд-материалы.

Для кого: **новым сотрудникам** — чтобы найти ответ на кадровый вопрос; **руководителям и
наставникам** — чтобы правильно вывести нового человека; **ДУП** — как рабочий архив.

Папка — часть Obsidian vault КМГ, ссылки `[[...]]` открываются кликом.

## Как читать имена файлов

`ТИП-НАПРАВЛЕНИЕ-НОМЕР Название.расширение`

| Пример | Разбор |
|---|---|
| `П-УП-003 Положение об оплате труда.pdf` | **П** — положение · **УП** — управление персоналом · **003** — номер в серии |
| `РС-УП-002 Расчёт отпусков и график на 2025 год.xlsx` | **РС** — расчёт/модель · **УП** · **002** · год в конце названия |
| `БР-ЛГ-001 Логотип КМГ горизонтальный.png` | **БР** — бренд-материал · **ЛГ** — логотипы · **001** |

Исключение — приказы: они сохраняют свой регистрационный номер, поэтому
`ПР-047-п График отпусков на 2025 год.docx` без сегмента направления.

Полная таблица кодов — в [[СТ-УП-001 Стандарт именования файлов|СТ-УП-001 Стандарт именования файлов]].

## С чего начать новому сотруднику

1. [[СП-УП-001 Книга нового сотрудника 2025.pdf|Книга нового сотрудника]] — прочитать целиком в первую неделю.
2. [[СВ-УП-001 FAQ по кадровым вопросам|FAQ по кадровым вопросам]] — держать под рукой: отпуска, зарплата, больничный, командировки, справки, куда звонить.
3. Дальше — по вопросу: деньги → П-УП-003, отпуска и соцпакет → П-УП-009, командировки и вахта → РГ-УП-007, режим и дисциплина → П-УП-001.

Руководителю, который выводит нового человека, — [[ЧЛ-УП-001 Чек-лист выхода нового сотрудника|чек-лист]];
назначенному наставнику — [[ПМ-УП-001 Памятка наставнику|памятка]].

## Как добавить новый документ

1. Определить тип по таблице кодов в [[СТ-УП-001 Стандарт именования файлов|СТ-УП-001]] и направление (`УП` — кадры).
2. Взять следующий свободный номер внутри своей серии. Номера, освободившиеся после вывода
   документа из обращения, не переиспользуются.
3. Назвать файл по формуле `ТИП-НАПР-НОМЕР Название.расширение`; название — как в шапке
   документа, год в конце, если документ привязан к периоду.
4. Обновить [[РЕ-УП-001 Реестр кадровых документов.base|реестр]] и проставить вики-ссылки:
   на вложения — с расширением и алиасом, на заметки `.md` — без расширения.
