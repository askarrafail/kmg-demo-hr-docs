# Матрица компетенций специалистов Департамента ИТ

> **Документ:** М-УП-007 · **Версия:** 1.4 · **Дата:** 03.03.2025
> **Владельцы:** Департамент управления персоналом, Департамент информационных технологий
> Применяется при подборе, ежегодной оценке, планировании обучения и формировании кадрового резерва

---

## Как читать матрицу

Каждая компетенция оценивается по четырёхуровневой шкале:

| Уровень | Название | Что означает |
|---|---|---|
| 1 | Знает | Понимает предмет, может объяснить. Работает под контролем |
| 2 | Умеет | Выполняет типовые задачи самостоятельно. Обращается за помощью в нестандартных случаях |
| 3 | Владеет | Решает нестандартные задачи. Может обучать других |
| 4 | Эксперт | Проектирует решения, определяет стандарты, выступает арбитром в спорных вопросах |

Целевой уровень — минимум для должности. Оценка ниже целевой на один уровень допустима на испытательном сроке и в первый год работы.

---

## Специалист технической поддержки

**Основная задача:** приём и решение обращений 1-й линии, эскалация того, что не решается.

| Компетенция | Целевой уровень |
|---|---|
| Работа с системой регистрации обращений | 3 |
| Диагностика проблем рабочих станций | 3 |
| Администрирование учётных записей | 2 |
| Поддержка пользователей SAP (базовые операции) | 2 |
| Поддержка ЭДО и ЭЦП | 3 |
| Настройка VPN и удалённого доступа | 2 |
| Работа с принтерами и периферией | 3 |
| Знание внутренних регламентов | 3 |
| Коммуникация с пользователями | 3 |
| Ведение документации по обращениям | 2 |

**Ключевая компетенция — коммуникация.** По статистике, заявки со скриншотом и внятным описанием закрываются в 2,3 раза быстрее. Умение специалиста задать пользователю правильные уточняющие вопросы влияет на срок решения сильнее, чем техническая квалификация.

## Специалист по сопровождению SAP

**Основная задача:** решение обращений 2-й линии по SAP, поддержка ключевых процессов.

| Компетенция | Целевой уровень |
|---|---|
| Модуль MM (закупки) | 3 |
| Модуль SD (сбыт, акты) | 3 |
| Модуль FI (финансы) | 2 |
| Модуль CO (контроллинг) | 2 |
| Настройка ролей и полномочий | 3 |
| Диагностика ошибок, анализ дампов | 3 |
| Работа с периодами проводки | 3 |
| Понимание учётных процессов компании | 3 |
| Взаимодействие с бизнес-подразделениями | 3 |
| Базовое знание ABAP (чтение кода) | 2 |

> **Про понимание учётных процессов.** Специалист, знающий транзакции, но не понимающий, зачем бухгалтерия закрывает период, будет решать симптомы. Ошибка M7 053 — первая по частоте (512 обращений за квартал), и правильный ответ на неё лежит не в SAP, а в понимании учётного цикла.

## Администратор инфраструктуры

| Компетенция | Целевой уровень |
|---|---|
| Администрирование Windows Server | 3 |
| Администрирование Linux (RHEL) | 3 |
| Active Directory, групповые политики | 3 |
| Виртуализация | 3 |
| Системы хранения данных | 3 |
| Резервное копирование и восстановление | 4 |
| Сетевые технологии | 2 |
| Мониторинг инфраструктуры | 3 |
| Обеспечение отказоустойчивости | 3 |
| Действия при инцидентах | 3 |

> **Резервное копирование — единственная компетенция уровня «Эксперт».** Причина в асимметрии последствий: ошибка в настройке мониторинга даёт неудобство, ошибка в резервном копировании обнаруживается в момент, когда восстанавливать уже нечего.

> **Про отказоустойчивость.** Разбор инцидента 17 мая 2025 года показал: резервный контроллер дискового массива не подхватил нагрузку из-за некорректной настройки после планового обслуживания. Компетенция включает не только настройку резервирования, но и **регулярную проверку его работоспособности**. Отказоустойчивость, которую не проверяли, — это предположение, а не отказоустойчивость.

## Порядок оценки

**Когда.** Ежегодно, в ноябре–декабре. Для новых сотрудников — дополнительно на 11-й неделе испытательного срока.

**Кто оценивает.** Непосредственный руководитель. Для уровней 3 и 4 требуется подтверждение руководителя департамента.

**Как проходит:**

1. Самооценка сотрудника по матрице
2. Оценка руководителем
3. Обсуждение расхождений
4. Согласование итоговой оценки
5. Формирование плана развития по компетенциям ниже целевого уровня

**Что даёт оценка.** Результаты влияют на пересмотр оклада, размер годовой премии, включение в кадровый резерв, план обучения на следующий год.

Сводка по департаменту — что требует внимания.

| Компетенция | Целевой уровень | Средняя оценка | Разрыв | Приоритет обучения |
|---|---|---|---|---|
| Ведение технической документации | 3 | 1,8 | −1,2 | **Высокий** |
| Обеспечение отказоустойчивости | 3 | 2,1 | −0,9 | **Высокий** |
| Понимание учётных процессов | 3 | 2,3 | −0,7 | Средний |
| Работа с периодами проводки | 3 | 2,4 | −0,6 | Средний |
| Взаимодействие с подрядчиками | 3 | 2,5 | −0,5 | Средний |
| Оптимизация производительности | 3 | 2,6 | −0,4 | Низкий |

**Два разрыва высокого приоритета связаны между собой.** Недостаток в документировании и в проверке отказоустойчивости — это один и тот же дефицит: работа считается выполненной, когда «заработало», а не когда описано и проверено.
